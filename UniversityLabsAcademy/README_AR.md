# University Labs Academy — Android

تطبيق موحّد للمختبرات الدراسية الأساسية فقط.

## المواد الموجودة
- Operating Systems — نظم التشغيل
- Analysis 1 — التحليل 1
- Algebra 1 — الجبر 1
- Algorithms and C — الخوارزميات و C
- Computer Engineering — هندسة الحواسيب

## تنظيم المحتوى
- لكل مقياس مختبر مستقل.
- تبقى المحاضرات والتمارين ضمن تنظيم كل مختبر كما ورد في محتواه الأصلي.
- لا يُنشأ قسم TP لمقياسي Algebra أو Analysis.
- مشروع Streaming English Academy مشروع جانبي مستقل، وليس جزءًا من هذا التطبيق.

## البناء عبر GitHub Actions من الهاتف
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. افتح تبويب Actions وشغّل workflow باسم Build Android APK.
3. بعد انتهاء البناء افتح نتيجة التشغيل ونزّل artifact باسم UniversityLabsAcademy-debug-apk.
4. فك ضغط artifact وثبّت app-debug.apk على هاتف Android.

## ملاحظة
هذا أرشيف مشروع Android وليس APK جاهزًا للتثبيت.


## تحديث الواجهة
تم تحسين الغلاف الرئيسي بواجهة حديثة متجاوبة، وألوان فاتحة/داكنة، وتبويبات أكثر وضوحًا، مع الإبقاء على محتوى المختبرات ووظائفها كما هي.
